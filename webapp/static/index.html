How it works (and how reliable it is)

Each image is segmented identically to the analysis pipeline (normalise → Otsu pore + multi-Otsu bright-particle thresholds → morphology; Inlens dark pixels refine fine cracks). Explainable features (phase fractions, pore/silicon sizes, texture, spatial stats) are scored against the Batch-3 envelope with a robust Mahalanobis distance; the nearest batch centroid gives the batch call and confidence.

Honesty: single images are unreliable (~45% leave-one-out accuracy — barely above chance). The group call on the median of 5+ images reaches ~97–100% for Batch-1-like samples. Use several locations of the same sample.

Second opinion: when an ETD/SE topography image is uploaded, a DINOv2 (deep) embedding of it is also scored with the same distance/centroid machinery — validated at ~100% group-of-5 accuracy for both batches. Its "why" is shown as the nearest dataset patches rather than plain words; treat the two calls together.

Assumption: the electrode is believed to be graphite (grey in BSE) with brighter silicon-based particles; black is pore or crack — inferred from image appearance, unconfirmed.
